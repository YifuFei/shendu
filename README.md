# 慎读

![慎读：阅读与拼音声调](store-listing/assets/promo-440x280.png)

遇到拿不准读音的汉字，选中它，右键查看拼音，再点一下听发音。

慎读是一款桌面浏览器扩展，帮助你在阅读网页时快速确认中文读音。支持简体、繁体中文，无需账号，拼音计算和朗读均在本机完成。

## 怎么用

1. 在网页正文中选中文字，例如“重庆”或“银行”。
2. 按右键，选择“显示中文拼音”。
3. 在文字附近查看原文和带调拼音：`chóng qìng`、`yín háng`。
4. 点击 🔊，朗读显示的中文。

每次最多显示选区中的前 **8 个汉字**，并参考周围文字判断常见多音字。只选“水”，就只朗读“水”，不会把周围的内容一起读出来。

点击浮层外部、按 Esc 或滚动页面即可关闭；不操作时，浮层会在 12 秒后自动消失。

## 安静、离线，按需使用

- 不需要注册或登录，没有广告。
- 只有你点击右键菜单后，才临时读取选区和有限的前后文。
- 不上传、不保存所选文字或浏览记录。
- 朗读只使用本地中文声音；没有可用声音时，仍可查看拼音。

详见[隐私政策](PRIVACY.md)。

## 使用时遇到问题？

**右键没有“显示中文拼音”？**  
先确认扩展已启用，并且选中了网页正文。直接打开的本地 HTML、浏览器内部页面、PDF、输入框和在线文档编辑器不在支持范围内。

**能看拼音，却不能朗读？**  
浏览器需要可用的本地中文声音。没有可用声音时，浮层会给出提示，慎读不会改用联网语音。

**多音字读音不对？**  
可以试着选中完整词语。拼音会参考有限上下文，但不能保证所有情况都正确；系统朗读对孤立多音字的判断，也可能与显示的拼音不同。
