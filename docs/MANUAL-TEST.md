# 人工验收清单

运行 `pnpm fixture`，在已加载开发构建的浏览器打开 `http://127.0.0.1:4173`。

- 选择“重庆”“银行”“行长”“行走”“音乐”“长大”，右键菜单只显示一个慎读项目。
- 点击菜单后，浮层在选区上方或下方出现，并显示对应原文和带调拼音。
- 选择超过 8 个汉字时，只显示前 8 个汉字及其拼音。
- 选择英文时显示 3 秒提示；输入框和 contenteditable 使用 selection-only 回退，不读取上下文。
- 点击扬声器可朗读；再次点击先停止上一次朗读。
- 点击外部、Esc、滚动、缩放、重新选择或等待 12 秒会关闭浮层。
- 在深色区域、200% 缩放和页面四角确认浮层未超出视口。
- 切换标签页、导航、快速连续选择时不显示上一选区内容。
- 在 Chrome/Edge 的扩展详情中确认没有网站长期访问权限。
